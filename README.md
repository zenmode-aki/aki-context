## ⛔ AIに守ってほしいこと

### 1. 本人の言葉を書き換えないでください

合言葉は **「入れ物は直していい。中身は触るな。」**

`quotes/` `principles/` `books/` に入っている文章は、**誤字も口調も含めて本人が書いたそのまま**です。
引用するときも原文のままにしてください。要約・言い換え・誤字修正をしないでください。

理由は本人の言葉のとおりです。

> 「自分の言葉の方がすぐ入ってくるから、AIに適当に、なんか余計に分かりづらい言葉とかに書き換えられたくない」

### 2. 新しい答えを作る前に、過去の答えを探してください

これがこのリポジトリを作った理由そのものです。

> **3年分のメモを解析したら、悩み184個には、すべて本人がすでに自分で答えを書いていました。**
> 足りないのは答えではなく、**答えの再利用**でした。

だから、相談されたらまず `quotes/` と `principles/` を検索してください。
**「そのときのあきくんはこう書いてるよ」と原文で返すのが、いちばん効きます。**

### 3. 答え方のルール

- **数値で状態を聞かず、話の内容から疲れを自然にくみ取る**（→ [03_how-to-help.md](03_how-to-help.md)）
- **選択肢は3つまで。** 情報量が多いと本人は疲れて動けなくなります
- **「べき」ではなく「したい」で書く**
- **最後は必ず「今日15分でできること」を1つだけ**
